# Banner Style Picker Implementation Plan (jiraPlane #10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tray-menu picker that lets the user choose the banner style (Cargo tag or Skywriter), persisted across restarts, with Skywriter ported as-is from the round-1 prototype.

**Architecture:** `main.js` reads/writes a gitignored `settings.json` and passes the chosen style to the overlay as a `banner` query param plus skywriter text bounds (`textX0`/`textX1`). `plane.html` branches on the param: cargo path is byte-for-byte today's behavior; skywriter path hides tag+rope, skips the pendulum sim, and lays the banner text down as smoke puffs along the flight path.

**Tech Stack:** Electron (menu-bar app), vanilla JS/CSS in one self-contained `plane.html`. Repo: `~/Developer/jiraPlane`.

**Spec:** `docs/superpowers/specs/2026-08-03-jiraplane-banner-picker-design.md` — read it first.

## Global Constraints

- **No test suite** (project rule). Every task's verify steps are manual: run the app or open `plane.html` in a browser. `TEST_FLIGHT=1 npm start` fires a flight on launch.
- All visuals stay in the single self-contained `plane.html`. No second HTML file, no external assets.
- Cargo path must remain exactly as accepted in #4/#6: tag, rope, pendulum constants (`G = 670, C = 5, L = 64`), margins (`-110%` entry, `+400px` exit), audio, flood valve, digest handling — untouched in both paths.
- `settings.json` and `state.json` are separate gitignored files; deleting dedup state (`state.json`, a documented debugging step) must not lose the style choice.
- Unknown/missing style anywhere → `cargo`. The app must run with no `settings.json`.
- Commits reference the issue as `refs #10` — do NOT write `fixes #10`; the issue closes only after owner acceptance (AGENTS.md protocol).
- This repo is PRIVATE but issues/commits are written as if public: no env values, credentials, or personal data.

Then add the layout function after `startAudio()` (before the pendulum section):

```js
/* ===== skywriter (#10, as-is port of design-directions round 1) =====
   Each letter is a fixed-position puff laid down at the point — and the
   moment — the plane's tail crosses its x. Multi-display: all coords are
   computed in global desktop px, converted to this window's local px once
   at launch; puffs outside the window simply clip. */
function layoutSkywriter() {
  const text = document.getElementById('banner').textContent;
  const sky = document.getElementById('sky');
  const durS = params.has('dur') ? +params.get('dur') / 1000 : 10;
  const multi = params.has('minX');
  const ox = multi ? window.screenX : 0; // global → local offset
  const oy = multi ? window.screenY : 0;
  // Plane-tail x span, mirroring the move animation: -110% rig entry, +400px exit
  const from = (multi ? +params.get('minX') : 0) - 1.1 * moveEl.offsetWidth;
  const to = (multi ? +params.get('maxX') : innerWidth) + 400;
  // Text bounds: 6%–88% of the primary display (multi) or the viewport (standalone)
  const x0 = multi ? +params.get('textX0') : innerWidth * 0.06;
  const x1 = multi ? +params.get('textX1') : innerWidth * 0.88;
  const baseY = (multi ? +params.get('flyY') : innerHeight * 0.32) + 40;
  const spacing = Math.min(26, (x1 - x0) / text.length);
  [...text].forEach((c, i) => {
    if (c === ' ') return; // spacing already reserves the slot
    const x = x0 + i * spacing;
    const t = ((x - from) / (to - from)) * durS; // moment the tail crosses x
    const y = baseY + 44 * Math.cos((2 * Math.PI * t) / (durS / 2)); // swoop sine
    const s = document.createElement('span');
    s.className = 'puff';
    s.textContent = c;
    s.style.left = x - ox + 'px';
    s.style.top = y - oy + 'px';
    s.style.animationDelay = `calc(var(--sync-delay, 0s) + ${t}s)`;
    // Compress the keyframe shape into the remaining flight time: early
    // letters linger (prototype feel), late letters dissipate quicker.
    s.style.animationDuration = durS - t + 's';
    sky.appendChild(s);
  });
}
```

if (bannerStyle === 'skywriter') {
