**Goal:** Three deliberately different standalone HTML mockups of the CodexBar-style tray
popover (#36), with fake data, so the owner can pick one before #38 builds the real window.

**Architecture:** Three single-file pages in `design-directions/`. Each draws the whole panel
(status header, recent-flights list, footer rows Test flight · Settings… · Quit) from one state
object through an idempotent `render(state)`. In a plain browser, a stand-in bridge supplies
fake state and a preset strip switches between the states the real panel must handle. The
winner becomes `popover.html` in #38 without a rewrite.

**Tech Stack:** Vanilla HTML/CSS/JS, inline, system fonts. No Electron, no new dependency.

**Spec:** No design spec. The decision record is issue #36's body (owner, 2026-09-24) and
issue #37. Read both: `gh issue view 37 --json body` and `gh issue view 36 --json body,comments`
(the plain `--comments` form prints only comments). The states the panel must handle come from
the Done-when lists of #39 and #40 (`gh issue view 39 --json body`, same for 40).

## The contract (every variant codes against this)

State. `render` draws only from this:

```js
// { lastPollAt: number | null,    // epoch ms of the last finished poll; null = none yet
//   pollingPaused: boolean,        // toggle on = paused (same sense as settings.html)
//   configError: string | null,    // set = polling is off; header shows it, not a time
//   flights: [{ issueKey: string, snippet: string, at: number }] }  // newest first, ≤ 5
```

This block goes at the end of `<body>` in every variant, verbatim:

```js
// Popover bridge (#37). #38 wires the real preload; its plan may rename these.
// In a plain browser there is no preload, so a local stand-in serves fake state.
const api = window.jiraPlanePopover || standaloneApi();
function standaloneApi() {
  document.body.classList.add('standalone');
  const now = Date.now();
  // Fake data only: never real issue keys or text from the owner's Jira.
  const FLIGHTS = [
    { issueKey: 'PROJ-142', snippet: 'Fix login redirect', at: now - 2 * 60e3 },
    { issueKey: 'OPS-77', snippet: 'Can you take a look at the retry logic before Friday? The staging run failed twice overnight.', at: now - 38 * 60e3 },
    { issueKey: 'PLATFORM-10482', snippet: 'Rename retry_backoff_multiplier_for_nightly_export_job_v2', at: now - 3 * 3600e3 },
    { issueKey: 'WEB-310', snippet: 'Swap the footer links for <FooterNav compact />', at: now - 26 * 3600e3 },
    { issueKey: 'PROJ-139', snippet: 'Bump timeout for the batch job', at: now - 4 * 86400e3 },
  ];
  const LIVE = { lastPollAt: now - 12e3, pollingPaused: false, configError: null, flights: FLIGHTS };
  const PRESETS = {
    flights: LIVE,
    empty: { ...LIVE, flights: [] },
    paused: { ...LIVE, pollingPaused: true },
    error: { lastPollAt: null, pollingPaused: false, flights: [],
             configError: 'Polling disabled: Jira URL or token missing in .env' },
  };
  let state = LIVE;
  let onState = () => {};
  const set = (next) => { state = next; onState(state); };
  document.querySelectorAll('[data-preset]').forEach((b) =>
    b.addEventListener('click', () => set(PRESETS[b.dataset.preset])));
  return {
    onState: (cb) => { onState = cb; cb(state); },
    setPaused: (paused) => set({ ...state, pollingPaused: paused }),
    replay: (index) => console.log('standalone: replay', state.flights[index].issueKey),
    testFlight: () => console.log('standalone: test flight'),
    openSettings: () => console.log('standalone: settings'),
    quit: () => console.log('standalone: quit'),
  };
}

function ago(at) {
  const s = Math.round((Date.now() - at) / 1000);
  if (s < 10) return 'just now';
  if (s < 60) return `${s}s ago`;
  if (s < 3600) return `${Math.floor(s / 60)}m ago`;
  if (s < 86400) return `${Math.floor(s / 3600)}h ago`;
  return `${Math.floor(s / 86400)}d ago`;
}

api.onState(render);
```

Rules for `render(state)` in each variant:

- The panel's root element is `<main class="panel">` (Task 1 Step 4 measures it).
- A full redraw on every call. Build rows with `createElement` + `textContent` (or clone a
  `<template>`). No `innerHTML` anywhere in the file.
- Status text: `configError` if set; else "Paused" if `pollingPaused`; else
  `Last poll ${ago(lastPollAt)}` (or "Waiting for first poll" when `lastPollAt` is null).
  A variant may shorten the times (`2m` for `2m ago`) but must start from `ago`.
- Pause control: checked/on when `pollingPaused`; disabled when `configError` is set; a click
  calls `api.setPaused(!state.pollingPaused)`.
- List: one row per `state.flights` entry, in order. A row click calls `api.replay(i)`. Zero
  flights → the text "No flights yet".
- Footer rows call `api.testFlight()`, `api.openSettings()`, `api.quit()`. Labels exactly
  **Test flight**, **Settings…** (with the ellipsis character), **Quit**.

The preset strip is markup in each variant, placed outside the panel:

```html
<nav class="presets">
  <button data-preset="flights">5 flights</button>
  <button data-preset="empty">Empty</button>
  <button data-preset="paused">Paused</button>
  <button data-preset="error">Config error</button>
</nav>
```

with `.presets { display: none; } body.standalone .presets { display: flex; }`.

Standalone stage (`body.standalone` only): a fake desktop. A wallpaper gradient with one light
region behind part of the panel (a worst case for text contrast). A 24 px fake menu bar across
the top with a small paper-plane glyph near the right end. The panel hangs a few px under that
glyph. Without `.standalone` (Electron), the body is transparent and the panel fills the window
at 0,0.

Shared look (all three): panel corner radius 10 px, a 1 px `rgba(255,255,255,0.12)` border, a
soft drop shadow. Tint `rgba(30,30,32,0.72)`, and under `body.standalone` only,
`backdrop-filter: blur(30px) saturate(150%)`. These are starting values; tune them by eye
against the CodexBar screenshot. Text colors from `settings.html`: `--text: #f0f0f0`,
`--muted: #8e8e8e`, `--accent: #2dd4bf`. The pause switch copies `settings.html`'s `.switch`
CSS (lines 144–153), scaled if the variant needs it. Row text 13 px. Secondary text no smaller
than 11 px (a guess at the legibility floor; the owner judges it at the pick).
